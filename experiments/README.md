# Эксперименты

Здесь собрано всё, что мы пробовали, с результатами (таблица пригодна для слайда «эксперименты»). Код финального пайплайна — в
`src/vacv_si/` и `configs/exp/final.yaml` (запуск: `python -m vacv_si run-all -c configs/exp/final.yaml`); разведочные скрипты —
в `experiments/analysis/` (они только читают данные и печатают числа, запускаются из корня репозитория после `run-all`).

**Как читать числа.** Валидация — повторный стратифицированный K-fold по 320 обучающим строкам (5 фолдов × 4–6 повторов).
*Brier* — качество вероятности «потолка» `SI = 10000` (меньше — лучше; константа даёт 0.189). *RMSE log10* — ошибка регрессии
`log10 SI` на не-потолочных строках (константа 1.049). *OOF-MSE* — метрика соревнования на всех строках (константа 22.08 M;
без единственной худшей строки — 18.66 M). «Честный» OOF-MSE означает, что блендинг, поправки и выбор моделей заново подгонялись внутри фолдов.

## Публичный лидерборд Kaggle (≈ 30% теста)

| посылка | счёт |
|---|---|

| финальная версия верхнего уровня | 4 326 281 |

Публичная часть — это ≈ 180 строк: одна выбросная запись (SI ≈ 25–36 тыс.) сдвигает счёт на миллионы, поэтому разрывы между
честными командами в несколько сотен тысяч статистически значимыми не являются (`analysis/12_leaderboard_noise.py`).

## Скрипты `analysis/`

Нумерация идёт в порядке работы: 01–06 — разведка данных (источники, шаблоны Title, стиль SMILES), 07–10 — внешние источники
(нужна сеть), 11–20 — разбор ошибок и проверка гипотез, 21–22 — проверка внешних наборов. Первая строка каждого файла — вопрос, на
который он отвечает.
